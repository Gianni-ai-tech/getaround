API Getaround – prix de location suggéré

Cette API suggère aux propriétaires un prix de location par jour (en euros) à partir des caractéristiques de leur voiture. Le modèle est un gradient boosting (scikit-learn) entraîné sur 4 840 voitures, suivi avec MLflow : R² de 0,77 et erreur absolue moyenne d'environ 11 € sur un jeu de test.

POST /predict

Prend une liste de voitures. Chaque voiture est une liste de 13 valeurs, dans cet ordre :

#VariableTypeExemple
1model_keytexte : marque (Citroën, Renault, BMW, Peugeot, Audi…)"Citroën"
2mileagenombre : kilométrage140411
3engine_powernombre : puissance (ch)100
4fueltexte : diesel, petrol, hybrid_petrol, electro"diesel"
5paint_colortexte : black, grey, blue, white, brown, silver…"black"
6car_typetexte : estate, sedan, suv, hatchback, subcompact, coupe, convertible, van"convertible"
7private_parking_availablebooléentrue
8has_gpsbooléentrue
9has_air_conditioningbooléenfalse
10automatic_carbooléenfalse
11has_getaround_connectbooléentrue
12has_speed_regulatorbooléentrue
13winter_tiresbooléentrue

Une valeur texte inconnue du modèle (une marque rare, par exemple) est acceptée et traitée comme une catégorie peu fréquente. Les booléens acceptent aussi 0 / 1 et "true" / "false".

Exemple de requête

{
  "input": [
    ["Citroën", 140411, 100, "diesel", "black", "convertible", true, true, false, false, true, true, true],
    ["Citroën", 13929, 317, "petrol", "grey", "convertible", true, true, false, false, false, true, true]
  ]
}

Exemple de réponse

{
  "prediction": [108.9, 262.53]
}

Chaque valeur est le prix suggéré par jour, en euros, dans l'ordre des voitures envoyées.

Erreurs

Code 422 avec un message explicite si une voiture n'a pas 13 valeurs, si mileage ou engine_power n'est pas un nombre, ou si une option n'est pas un booléen.

Appeler l'API

curl

curl -i -H "Content-Type: application/json" -X POST \
  -d '{"input": [["Citroën", 140411, 100, "diesel", "black", "convertible", true, true, false, false, true, true, true]]}' \
  https://VOTRE-URL/predict

Python

import requests

response = requests.post("https://VOTRE-URL/predict", json={
    "input": [["Citroën", 140411, 100, "diesel", "black", "convertible", True, True, False, False, True, True, True]]
})
print(response.json())

À propos du modèle

Pipeline scikit-learn : encodage one-hot des variables texte (catégories de moins de 10 voitures regroupées), standardisation du kilométrage et de la puissance, puis HistGradientBoostingRegressor. Comparé avec MLflow à une régression linéaire (R² 0,71), une régression Ridge (0,71) et une forêt aléatoire (0,75). Les variables les plus influentes sont la puissance, le kilométrage et la marque.
