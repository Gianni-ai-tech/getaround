# Dashboard Getaround – délai minimum entre deux locations

Aide le Product Manager à choisir le seuil (minutes) et le périmètre (toutes les voitures ou Connect seulement) d'un délai minimum entre deux locations : locations bloquées, revenu touché, cas problématiques évités.

Application Streamlit exécutée directement dans le navigateur avec [stlite](https://github.com/whitphx/stlite) (premier chargement : 20 à 40 secondes).

Projet Jedha (bloc 5, CDSD) – Gianni Murru.
